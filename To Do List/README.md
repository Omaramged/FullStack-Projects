# To-Do List Project

A simple Full-Stack To-Do List application built with Next.js (Frontend) and Express + MongoDB (Backend).

## Project Structure

- `frontend/` - Next.js App Router, React, Tailwind CSS
- `backend/` - Express.js, MongoDB (Mongoose)

## Getting Started

### 1. Setup Backend
1. Open terminal and navigate to `backend/` folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm run dev
   ```

### 2. Setup Frontend
1. Open a new terminal and navigate to `frontend/` folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```

### 3. Open App
Go to [http://localhost:3000](http://localhost:3000) in your browser.
